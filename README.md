# 志工服務報名系統

單一 HTML 檔的志工/廠工服務排班報名工具，目前資料存於瀏覽器 localStorage，規劃後續改接 Supabase 雲端資料庫。

## 功能

- **報名**：選姓名（頭像卡片牆，可上傳頭像）→ 不用登入即可報名；可用「我有空的日期」月曆篩選、依狀態篩選
- **總覽**：人員 × 活動矩陣，點格子可標記「實際出席」
- **報表**：整體參與概況、各課室參與率、本月未參與名單、出席登記
- **設定**：
  - 日期/活動：單次（月曆複選）、每週固定（可設結束日、可停辦某一次並復原）
  - 人員：名單管理、頭像、課室指定、停用/刪除
  - 課室：課室清單管理（新增/更名/刪除，人員自動同步）
  - 地點庫、JSON 匯出入備份

## 使用方式

用瀏覽器（建議 Chrome / Edge）開啟 `index.html` 即可。第一次使用可到「設定 → 資料 → 重置為範例資料」載入 2026 年 7 月範例。
